🖥️ Computer Basics

Learn the fundamental concepts of computers

What is a Computer?

A computer is an electronic device that receives data, processes it according to instructions, stores information, and produces useful output.

Computers are used in many areas including education, business, healthcare, science, communication, and entertainment.

Basic Computer Operations

  • Input data and instructions.
  • Process information.
  • Store data and results.
  • Produce output.
  • Communicate information with other systems.

Main Components

🧠 CPU

The Central Processing Unit (CPU) executes instructions and performs calculations required by computer programs.

💾 RAM

Random Access Memory (RAM) provides temporary storage for data and programs that are currently being used.

💽 Storage

Storage devices such as SSDs and hard drives are used to store data and programs for longer periods.

⌨️ Input Devices

Input devices allow users to provide data and commands to a computer. Examples include keyboards, mice, microphones, and scanners.

🖥️ Output Devices

Output devices present processed information to the user. Examples include monitors, speakers, and printers.

Hardware and Software

🔧 Hardware

Hardware refers to the physical components of a computer system, such as the CPU, memory, motherboard, storage, keyboard, and monitor.

💿 Software

Software consists of programs and instructions that tell computer hardware what tasks to perform.

Operating Systems

An operating system is system software that manages computer hardware and provides services for application programs.

🪟 Windows

A widely used operating system developed by Microsoft for personal computers and other devices.

🐧 Linux

An open-source operating system widely used in servers, development environments, embedded systems, and desktops.

🍎 macOS

Apple's desktop operating system designed for Mac computers.

Files and Folders

Computers organize information using files and folders. A file stores data, while a folder is used to organize related files and other folders.

  • Documents can contain text and other information.
  • Images store visual information.
  • Videos contain moving visual and audio content.
  • Folders help organize files into logical groups.

Learning Objectives

After studying this lesson, you should be able to:

  • Explain what a computer is.
  • Identify the main components of a computer.
  • Distinguish between hardware and software.
  • Explain the purpose of an operating system.
  • Understand the basic organization of files and folders.

Quick Question

Which component is responsible for executing program instructions and performing calculations?

Answer: CPU
