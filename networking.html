1️⃣ Introduction to Networking

Computer networking is the practice of connecting computers, servers, mobile devices, and other systems so they can communicate and exchange information.

Networks can be very small, such as a home network, or extremely large, such as the global Internet.

Why do we use networks?

  • Sharing files and information.
  • Sharing hardware such as printers.
  • Accessing Internet services.
  • Communicating between users and systems.
  • Providing access to applications and services.

2️⃣ What is a Network?

A computer network is a group of interconnected devices that communicate with each other using defined communication rules called protocols.

A network normally contains devices, communication media, network hardware, software, and protocols.

Simple Example

Imagine a small office with ten computers, a network switch, a router, and a printer. The computers can communicate with each other, access the printer, and connect to the Internet.

3️⃣ Network Components

Networks contain different devices, each performing a specific role.

💻 Client

A client is a device or application that requests services or resources from another system.

🖥️ Server

A server provides services, applications, data, or resources to clients.

🔀 Switch

A network switch connects devices within a local network and forwards data to the appropriate device.

📡 Router

A router connects different networks and determines where network traffic should be forwarded.

📶 Wireless Access Point

A wireless access point allows wireless devices to connect to a network using Wi-Fi.

🛡️ Firewall

A firewall controls network traffic according to defined security rules and can help protect systems from unauthorized access.

4️⃣ Types of Networks

👤 PAN — Personal Area Network

A PAN connects devices around an individual, such as a smartphone, smartwatch, and wireless headphones.

🏠 LAN — Local Area Network

A LAN connects devices within a limited geographical area such as a home, school, or office.

📶 WLAN — Wireless Local Area Network

A WLAN is a local network that uses wireless communication technologies such as Wi-Fi.

🏙️ MAN — Metropolitan Area Network

A MAN connects networks across a larger area, such as a city or metropolitan region.

🌍 WAN — Wide Area Network

A WAN connects networks across large geographical areas. The Internet is the largest example of an interconnected global network.

5️⃣ Client and Server

Many network applications use a client-server model. The client requests a service, while the server provides that service.

Example: Visiting a Website

When you open a website, your browser acts as a client. It sends requests to a web server, and the server responds with the requested resources.

Simple Communication

Client → Request → Server

Client ← Response ← Server

6️⃣ Network Topologies

Network topology describes how devices and connections are arranged within a network.

⭐ Star Topology

Devices connect to a central device, usually a network switch.

🔗 Bus Topology

Devices share a common communication medium. This topology is mostly of historical importance in modern networks.

🔄 Ring Topology

Devices are connected in a circular arrangement. Each device is connected to other devices in the ring.

🕸️ Mesh Topology

Devices have multiple connections to other devices, providing redundancy and alternative communication paths.
