# IT Learning Hub

A simple educational website for learning the fundamentals of Information Technology.

## About

IT Learning Hub introduces basic concepts of Information Technology in a simple and easy-to-understand way.

## Topics

- Computer Basics
- Networking
- Cybersecurity

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Project Goal

This project was created as a simple practical project to learn Git and GitHub workflows, including commits, branches, pull requests, merging, and remote repositories.
